# DVISION 디지털 명함

(주)디비전 사내용 **디지털 명함 · 이메일 서명** 서비스입니다.

직원이 자기 프로필을 한 번 입력해두면, 링크로 공유하는 공개 명함과 메일에 붙여넣는 이메일 서명이 자동으로 만들어집니다. 종이 명함을 새로 찍거나 서명을 사람마다 다르게 만들 필요 없이, 회사 전체가 같은 형식을 씁니다.

## 무엇을 할 수 있나요

- **공개 디지털 명함** — 링크 하나로 공유하는 모바일 명함. 카카오톡·문자로 보내면 명함 카드가 미리보기로 뜹니다.
- **연락처 저장** — 상대가 버튼 한 번으로 폰 연락처에 바로 저장합니다.
- **이메일 서명** — 명함 이미지가 들어간 서명을 복사해 Gmail·Outlook·네이버 메일에 붙여넣습니다.
- **프로필 편집** — 영문명·직함·소개·사진을 직접 수정하고 결과를 바로 미리봅니다. 이름·이메일·휴대전화는 인사 시스템 값이 그대로 들어갑니다.
- **임직원 관리** — 인사 시스템의 재직자 목록에서 명함 권한 · 주소 · 비밀번호를 관리합니다.

## 구성

```
브라우저 ──▶ Next.js (이 저장소) ──X-Internal-Key──▶ 명함 서버 (dvision-namecard-server, Spring Boot) ──▶ MySQL
                                                                              ├─ hrm 스키마 (인사, 읽기 전용)
                                                                              └─ namecard 스키마 (명함 전용)
```

- **직원은 인사 시스템(DVI-hrm-backend)에서 옵니다.** 이름 · 이메일 · 휴대전화 · 재직 상태는 인사가 원본이고 명함에서는 고치지 않습니다. 명함 서버가 인사 스키마의 `employee` 를 직접 조인해 읽습니다 — 복사본이 없어 동기화도 없습니다.
- 명함 스키마에는 인사에 없는 값만 있습니다: 공개 주소(slug) · 영문명 · 직위/직책/부서(영문 포함) · 소개 · 사진 · 회사/사업장 · 명함 권한과 비밀번호.
- 입사자는 인사에 등록되면 임직원 목록을 열거나 본인이 로그인할 때 명함이 자동으로 만들어집니다. 퇴사는 인사에서 처리하면 그 순간 명함 · 사진 · 로그인이 닫힙니다. 명함 쪽에는 직원 추가 · 삭제 · 상태 변경이 없습니다.
- 명함 서버는 Next 서버만 부릅니다(공유 키). **외부에 열지 마세요** — 사용자 권한 확인은 Next 가 하고 옵니다.

## 로그인

이메일 + 비밀번호, 또는 사내 통합 로그인(SSO). 세션은 자체 발급한 JWT 쿠키입니다.

- 인사 시스템에 등록된 재직자만 들어옵니다.
- SSO 는 인사의 `sso_username`(Keycloak 아이디)으로, 없으면 이메일로 직원을 찾습니다.
- 비밀번호를 아직 못 받은 직원은 공용 비밀번호로 들어옵니다(관리자 제외). 관리자는 **임직원 관리**에서 개인 비밀번호를 발급합니다.
- 권한(직원 · 관리자)은 명함이 관리합니다. 마지막 관리자의 권한을 내리는 것은 서버가 막습니다.

### 첫 관리자 만들기

관리자가 아직 없으면 발급 화면에 들어갈 수 없습니다. 이때만 스크립트를 씁니다(명함 서버가 떠 있어야 합니다).

```bash
pnpm admin:password <이메일>          # 관리자로 발급
pnpm admin:password <이메일> --member # 일반 직원으로 발급
```

인사 시스템에 등록된 이메일이어야 합니다.

## 실행

먼저 명함 서버를 띄웁니다. DB 준비와 서버 환경변수는 명함 서버 저장소(`dvision-namecard-server`)의 README 에 있습니다. 기존 Neon 데이터를 옮기는 방법도 거기 적어 두었습니다.

그다음 `.env.example` 을 `.env` 로 복사해 `NAMECARD_API_URL` · `NAMECARD_API_KEY` · `SESSION_SECRET` 을 채우고

```bash
pnpm install
pnpm dev
```
